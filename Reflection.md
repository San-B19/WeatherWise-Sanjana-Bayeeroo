For the WeatherWise project, I primarily used ChatGPT as my Al development assistant. This tool was instrumental throughout the entire design and coding process. It helped me move from a basic weather-fetching function to a fully modular, user-friendly, and intelligent weather advisory system. I used ChatGPT not just to generate code, but also to understand how to structure my program logically, handle errors gracefully, and integrate advanced features like natural language processing, timezone adjustments, and interactive plotting. The ability to interact with ChatGPT in real-time allowed me to explain my challenges and receive contextual solutions, which accelerated both my problem-solving and my learning.
The prompting techniques I applied were deliberate and strategic. Rather than simply asking for code snippets, I described the problems I faced in detail. For example, when the original code failed to recognize small towns or remote locations, I asked ChatGPT how to convert city names into coordinates for more accurate weather retrieval. I used follow-up prompts to refine the parser that extracts user intent from natural language queries and to include features such as emoji-based feedback, sunrise/sunset times, and dynamic data visualisation. I approached each function as a separate module, which I improved step-by-step through targeted prompting asking for better input handling, chart styling, or more natural-sounding responses. This method of prompting helped me refine not just the code, but also my thinking as a developer.
One thing I'm especially proud of is how the app evolved into a natural language driven interface. Users can now ask questions like "Will it rain in Rose-Hill tomorrow?" and receive rich, friendly responses that include temperature, humidity, wind, and even sun timings all personalized based on geolocation. The way I was able to combine various libraries like geopy, pyinputplus, matplotlib, and pytz, with Al guidance, to build something both functional and engaging is something I didn't think I could achieve at the start of the project.
If I had more time, I would improve the natural language parser even further by integrating a lightweight NLP model like spaCy. This would allow the system to handle more complex queries and better understand user intent. Additionally, I would add unit tests for all critical functions to ensure the app remains reliable as it scales.
In conclusion, this project taught me not just Python programming, but also how to think modularly, anticipate user needs, and use Al tools to co-create robust applications. The intentional prompting process was key it turned ChatGPT into a collaborative partner that enhanced both my coding and my confidence.
This assignment has genuinely expanded my technical abilities and reshaped how I approach problem-solving in code.
