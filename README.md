# WeatherWise-Sanjana-Bayeero
Step 1- Run the App
Make sure all required packages are installed. Then launch the application using:python weatherwise.py
Or if you're using a Jupyter Notebook/Colab, run all the cells in order

Step 2: Enter Your API Key
The first time you run the app, it will ask: Please enter your OpenWeatherMap API Key:Paste your API key from https://openweathermap.org/api
Press Enter: Your key will be saved temporarily for the session.

Step 3: Provide a Location
You’ll see this prompt: Which city or location would you like the weather for? (or type 'exit' to quit):
Enter a city or location name (e.g.,Moka , Port Louis)
The app will find the exact location using geocoding

Step 4: Ask a Weather Question
You’ll be asked: What weather information would you like? (e.g., 'temperature tomorrow', 'rain today', 'forecast'):
You can type natural phrases like:
"Will it rain tomorrow?"
"What's the temperature today?"
"How windy will it be this weekend?"
"Tell me the forecast in 5 days."
"Sunrise and sunset in London today"
 The app will understand common terms like today, tomorrow, weekend, and in 5 days
It also recognizes weather types like temperature, rain, humidity, wind, sunrise/sunset, etc.

 Step 5: Read the Weather Report
 WeatherWise will respond with a natural-language weather summary. Example:
For Port Louis  tomorrow: Expect about 4.5mm of rain in the 3 hours around that time. Humidity will be 82%. Wind speeds around 3.5 m/s.
If available, it also adds sunrise/sunset times for the current day.

 Step 6: View Charts (Optional)
After receiving the weather report, you’ll be asked: Do you want to see 5-day temperature and precipitation charts? (yes/no):
Type yes to view:
A temperature line graph
A precipitation bar chart (rain + snow)
Type no to skip this step

Step 7: Exit the App
To end your session, type: exit

You’ll see: Goodbye! Stay weather-wise!
